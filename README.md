# سامانه اعتباری نوید امید (سانا) — طرح نگین میثاق

بازنویسی پنل HTML تک‌فایلی به یک پروژه React ماژولار.

**استک:** React 19 · TypeScript · Vite 8 · Ant Design 6 (RTL + fa_IR) · React Hook Form · Yup · TanStack React Query 5 · React Router 7 · Zustand · Recharts · ExcelJS

## اجرا

```bash
npm install
cp .env.example .env   # VITE_DEMO_DATA=true → داده و کاربران نمونه
npm run dev            # http://localhost:5173
npm test               # تست‌های واحد منطق کسب‌وکار (Vitest)
npm run build          # tsc + vite build
```

کاربران دمو: `admin/admin` (مدیر سامانه) — `manager`، `hr`، `credit`، `digital` با رمز `123456`.
داده‌ها در `localStorage` (کلید `sana-db-v1`) ذخیره می‌شوند؛ برای ریست، آن کلید را پاک کنید.

## ساختار

```
src/
  app/          Providers، Router، Layout، Guardها (احراز هویت و دسترسی تب)، theme
  api/          «بک‌اند» Mock: توابع async با شکل REST + اعتبارسنجی سمت سرور + لاگ تغییرات
  queries/      هوک‌های React Query، query key factory، useApiMutation، usePermissions
  domain/       منطق خالص کسب‌وکار (محاسبه اعتبار، شرایط مجاز بودن، مجوزها) + تست‌ها
  lib/          تاریخ شمسی، اعداد فارسی، مبلغ به حروف، اعتبارسنج‌ها، اکسل
  components/   پل RHF↔antd (RHFInput, RHFSelect, RHFDate, RHFAmount, ...)، DatePicker شمسی، ...
  features/     یک پوشه برای هر تب: settings, companies, staff, credit, approvals, dashboard, users, audit
  store/        Zustand: نشست کاربر، شرکت انتخاب‌شده
```

جریان داده: `Component → useQuery/useApiMutation → api/*.api.ts → (Mock: localStorage | واقعی: axios)`.
برای اتصال به بک‌اند واقعی **فقط** بدنه توابع `src/api/*.api.ts` با درخواست HTTP جایگزین می‌شود؛ هوک‌ها و UI تغییر نمی‌کنند.

### 🐞 باگ‌های نسخه HTML که اصلاح شد

1. **مدیر شرکت نمی‌توانست درخواستی را رد کند**: فیلد «دلیل رد» برای `mgrReject` مخفی بود ولی اجباری چک می‌شد.
2. **درخواست ردشده توسط مدیر شرکت هنوز اعتبار مصرف می‌کرد**: فقط `'رد شده'` کسر می‌شد، نه `'رد شده توسط مدیر شرکت'`.
3. **یک درخواستِ ردشده مانده انباشته ماه بعد را قفل می‌کرد**: `usedMonths` هنگام ثبت پر می‌شد و هیچ‌وقت پاک نمی‌شد. حالا از درخواست‌های معتبر محاسبه می‌شود.
4. «در انتظار» داشبورد درخواست‌های در انتظار مدیر شرکت را حساب نمی‌کرد.
5. فیلتر ماه رتبه‌بندی هیچ‌وقت پر نمی‌شد.
6. XSS: نام شرکت/پرسنل با `innerHTML` درج می‌شد (React به‌صورت پیش‌فرض escape می‌کند).
7. `prompt()` برای علت عدم اعطا → Modal با Select.
8. حذف پرسنلی که درخواست وام دارد، داده یتیم می‌ساخت (حالا مسدود است).

### ⚠️ چیزهایی که **باید** در بک‌اند واقعی انجام شوند (Mock کافی نیست)

- **رمز عبور:** الان در Mock به‌صورت متن ساده است. در سرور: hash با argon2/bcrypt؛ رمز هرگز به کلاینت برنگردد.
- **احراز هویت:** توکن در کوکی `httpOnly` (نه localStorage)؛ refresh token.
- **دسترسی‌ها:** `usePermissions` فقط برای مخفی‌کردن دکمه‌هاست. هر endpoint باید نقش/مجوز را چک کند.
- **تاریخ مبنا:** فیلد «تاریخ مبنای محاسبه» در تب تخصیص وام فقط برای تست است؛ سرور باید ساعت خودش را ملاک بگیرد، وگرنه قانون «روز مجاز انتقال» دور زده می‌شود.
- **همزمانی:** دو کاربر ممکن است هم‌زمان از یک اعتبار برداشت کنند → تراکنش دیتابیس یا optimistic locking (`version`).
- **مبالغ:** در دیتابیس `DECIMAL`/`BIGINT` (ریال)، نه float.
- **فایل‌ها:** آپلود multipart، بررسی نوع/حجم، ذخیره در object storage. الان فقط نام فایل ذخیره می‌شود.
- **لاگ تغییرات:** append-only در سرور، با IP و شناسه کاربر؛ بازگردانی باید خودش یک عملیات جدید و قابل ممیزی باشد (همین الان هم این‌طور است).
